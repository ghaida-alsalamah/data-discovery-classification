# Metacrafter attribution

The optional evaluation imports Metacrafter 2.0.0, by Ivan Begtin and contributors, and uses its bundled registry snapshot 1.3.0 and pinned rules pack v0.0.8. These are distributed by APICrafter under Apache License 2.0.

- [Metacrafter source and license](https://github.com/apicrafter/metacrafter)
- [Rules pack source and license](https://github.com/apicrafter/metacrafter-rules)
- [Registry source and license](https://github.com/apicrafter/metacrafter-registry)

The project does not vendor upstream implementation code. Installing the pinned wheel preserves its distribution license. The bootstrap retains the original registry manifest and extracts the original rule pack with its included license notices. The local crosswalk, evaluation adapter, fixture generator, and Saudi rule hook definitions were authored for this project.
